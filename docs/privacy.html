ChatYUE 隐私政策

版本 1.1 ｜ 生效日期：2026-10-14

本政策说明 ChatYUE（以下简称“本应用”）如何处理你的信息。本应用不设账号、不收集身份信息、不含广告与第三方统计 SDK。

一、我们处理哪些信息

信息用途存储位置
你输入的聊天内容发送给固定接口以获取回答本机数据库；发送时经网络传输
历史对话与标题在本机展示与搜索仅本机，卸载即删除
你选择的图片作为附件展示读取设备图片，仅在本机展示；图片内容不会上传
你选择的 txt 文本读取内容并作为提问的一部分读取后随消息发送给接口
联网搜索关键词在你开启联网搜索时检索公开资料发送给公开搜索服务（DuckDuckGo、维基百科）
协议同意状态避免重复提示仅本机的应用私有存储

二、权限说明

  • 网络权限：用于访问固定接口、联网搜索与检查更新。
  • 读取图片（相册）权限：仅当你主动点击「选择图片」时申请，用于列出设备中的图片供你选择。拒绝后仍可正常聊天，只是无法选择图片。
  • 本应用不会读取或上传你的通讯录、短信、位置、通话记录等信息。

三、数据如何流动

  1. 你的消息会通过明文 HTTP 发送到本应用内置的固定接口，再由该接口转发给上游模型服务。请注意：该链路不是端到端加密，请勿发送密码、身份证号等敏感信息。
  2. 开启联网搜索时，你的关键词会发送给 DuckDuckGo 与维基百科的公开接口，用于检索公开资料。
  3. 「检查更新」与「更新日志」会请求本项目的 GitHub Pages 静态文件。
  4. 除上述场景外，本应用不会向任何第三方提供你的信息。

四、数据保留与删除

  • 聊天记录保存在本机数据库中，可在应用内「清空历史记录」删除，或通过系统卸载应用一并删除。
  • 本应用没有服务器端存储，开发者无法访问你的聊天记录。

五、未成年人保护

本应用不面向 14 周岁以下未成年人。未成年人应在监护人指导下使用，并在监护人同意本政策后使用。

六、政策更新

本政策以本网页版本为准，可能随时更新，更新后在本页面发布即生效。

七、联系方式

如有疑问，可通过 项目 Issues 与我们联系。
